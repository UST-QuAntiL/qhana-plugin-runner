Relations (``relation/*``)
==========================

+-----------------+--------------------------------------------------------------+
| data type       | relation/*                                                   |
+-----------------+--------------------------------------------------------------+
| content types   | text/csv, application/json, application/X-lines+json         |
+-----------------+--------------------------------------------------------------+

The ``relation/*`` data type describes the most generic relation format.
See :ref:`data-formats/data-model:relations` for more details.


.. todo:: The examples in this document can (and should) be replaced with shortened real world examples once they are available to make testing new plugins easier.

Data Types
----------

relation/list
^^^^^^^^^^^^^

The data contains a list of generic relations.


relation/distance
^^^^^^^^^^^^^^^^^

The relations encode distance between two entities.
Distance relations have a single numeric ``distance`` attribute.
Distances are unitless and must be positive or 0.

Additional attributes should be ignored.

Example:

.. code-block:: text

    source,target,distance
    entA,entB,0.7
    entB,entC,2
    entB,entB,0


relation/unit-distance
^^^^^^^^^^^^^^^^^^^^^^

Same as ``relation/distance``, but with an additional ``unit`` attribute.
The ``unit`` attribute gives the distance a specific unit, e.g., ``m`` for meters, ``km`` for kilometers, etc.
When converted to ``relation/distance``, all distances **must** first be converted to the same unit!

Additional attributes should be ignored.

.. code-block:: text

    source,target,distance,unit
    entA,entB,0.7,m
    entB,entC,2,m
    entB,entB,0,m


relation/similarity
^^^^^^^^^^^^^^^^^^^

The relations encode similarity between two entities.
Similarity relations have a single numeric ``similarity`` attribute.
Similarities are unitless and must be between 1 (for maximum similarity) or 0 (for no similarity) including both ends.
A relation from an entity to itself must always have a similarity of 1.

Additional attributes should be ignored.

Example:

.. code-block:: text

    source,target,similarity
    entA,entB,0.8
    entB,entC,0.2
    entB,entB,1


relation/attribute-distances
^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Represents distances between two :ref:`entities <data-formats/data-model:entities>` based on a single specific attribute.
The records use the same schema as ``relation/distance``, but the data is delivered as an ``application/zip`` archive containing one ``.json`` file per attribute, and ``distance`` can be ``null`` to mark a missing value.

**JSON Schema (per attribute file):**
A list of objects representing pairwise distances:

* ``source`` (string): ID of the first entity.
* ``target`` (string): ID of the second entity.
* ``distance`` (float | null): The calculated distance score. Can be null if missing or invalid.

**Example:** Attribute ``dominanteCharaktereigenschaft`` of the MUSE dataset.

.. code-block:: json

    ...
    {
    "source": "44_21_1",
    "target": "45_7_2",
    "distance": 0.5
    },
    ...

| *ID 44_21_1 is the ID of entity with dominanteCharaktereigenschaft=aktiv*
| *ID 45_7_2 is the ID of entity with dominanteCharaktereigenschaft=gut*

**Example Usage**

* Output generated by :ref:`sim-to-dist-transformers`.
* Input needed for :ref:`distance-aggregator`.


relation/attribute-similarities
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Represents pairwise similarity scores between two :ref:`entities <data-formats/data-model:entities>` based on a single specific attribute.
The records use the same schema as ``relation/similarity``, but the data is delivered as an ``application/zip`` archive containing one ``.json`` file per attribute.

**JSON Schema (per attribute file):**
A list of objects representing pairwise similarities:

* ``source`` (string): ID of the first entity.
* ``target`` (string): ID of the second entity.
* ``similarity`` (float | null): The calculated similarity score.

**Example:** Attribute ``dominanteCharaktereigenschaft`` of the MUSE dataset.

.. code-block:: json

    ...
    {
    "source": "44_21_1",
    "target": "45_7_2",
    "similarity": 0.5
    },
    ...

| *ID 44_21_1 is the ID of entity with dominanteCharaktereigenschaft=aktiv*
| *ID 45_7_2 is the ID of entity with dominanteCharaktereigenschaft=gut*

**Example Usage**

* Output generated by :ref:`sym-max-mean`.

relation/element-similarities
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Represents pairwise similarity scores between two element values of :ref:`entities <data-formats/data-model:entities>` based on their taxonomy.
Unlike ``relation/similarity``, ``source`` and ``target`` contain attribute values (elements) instead of entity IDs, and the data is delivered as an ``application/zip`` archive containing one ``.json`` file per compared attribute.

**JSON Schema (per attribute file):**
A list of objects representing the element-to-element similarity:

* ``source`` (string/any): The first attribute value/element being compared.
* ``target`` (string/any): The second attribute value/element being compared.
* ``similarity`` (float): The calculated similarity score (e.g., Wu-Palmer score).

**Example:** Attribute ``dominanteCharaktereigenschaft`` of the MUSE dataset.

.. code-block:: json

    ...
    {
    "source": "aktiv",
    "target": "gut",
    "similarity": 0.5
    },
    ...


**Example Usage**

* Output generated by :ref:`wu-palmer`.
* Input needed for :ref:`sym-max-mean`.


relation/entity-distances
^^^^^^^^^^^^^^^^^^^^^^^^^

Represents the total, aggregated distance between two :ref:`entities <data-formats/data-model:entities>` across multiple attributes.
The records use the same schema as ``relation/distance``, delivered as a single ``application/json`` file.

**JSON Schema:**
A list of objects representing the aggregated entity-to-entity distance:

* ``source`` (string): ID of the first entity.
* ``target`` (string): ID of the second entity.
* ``distance`` (float): The aggregated distance score (e.g., Mean, Median, Max, Min).

**Example:** Attribute ``dominanteCharaktereigenschaft``, ``dominanteFarbe``, ``dominanterAlterseindruck``, ``dominanterZustand``, ``genre`` of the MUSE dataset.

.. code-block:: json

    ...
    {
    "source": "44_21_1",
    "target": "45_7_2",
    "distance": 0.5133333333333334
    },
    ...

| *ID 44_21_1 is the ID of entity with dominanteCharaktereigenschaft=aktiv*
| *ID 45_7_2 is the ID of entity with dominanteCharaktereigenschaft=gut*

**Example Usage**

* Output generated by :ref:`distance-aggregator`.
* Input needed for :ref:`mds`.
