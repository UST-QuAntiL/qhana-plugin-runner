QLCM-notation is a notation for quantum circuits and looks like this:

[
	[block 1],
	[block 2],
	[block 3],
	...
]

A block is an element of the quantum circuit like for example a qubit or a gate and includes a unique id, a step declaration that defines what kind of circuit element this block is and a list of inputs and outputs which are the preceding or following blocks in the circuit. If there are no inputs or outputs the corresponding list stays empty.


In the following, the input and output fields of each blocks contain only the number of possible inputs or outputs (for example "outputs: [2]").
In your generated model this should be a concrete list of the outputs (like "outputs: [H_0, Msr_1]") 

These are the representations for the possible blocks (But the input and output lists are filled with the maximum possible length of the list instead of an actual list):

Possible blocks:

1. A Qubit is represented like this:
[id: "Q_n", step: "Qubit", inputs: [0], outputs: [1]]

Important rules:
Before you can use any quantum Arithmetic operator, you have to encode classical bits and numbers.

If not specified to use classical clustering, the default clustering block used should be the QuantumCLustering Block.

UniformSuperposition means that you apply one very Qubit a hadamard operation. If you create a model that uses multiple qubits with a hadamard each, it is preferred to use a PrepareState with a uniform superposition to implements this!

If a valid representation exists using a PrepareState node, it MUST be used and all equivalent decompositions into gates (Hadamard, CNOT, Pauli-Z)  are forbidden.

When a PrepareState is used, it fully replaces all qubit initialization and no additional Qubit nodes are allowed.
All multi-qubit entangled states (GHZ, Bell, W) must be represented as a single PrepareState node with a parameter value = n. No decomposition is allowed.

Do not have unnecessary Qubits added. If only a set of prepared sates is wanted, the only have those and no additional qubits.

If a gate is applied to multiple qubits, it must be represented as multiple independent gate instances, one per qubit

Do never invent any new blocks that are not given in the list above!
