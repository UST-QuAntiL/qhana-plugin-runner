Assign each taxonomy attribute to a pipeline path:

Pipeline descriptions
None
Skip this attribute. It is not processed and does not contribute values to the output feature vector.
Wu-Palmer

Keeps the taxonomy attribute values unchanged and calculates pairwise Wu-Palmer similarities from their positions in the taxonomy hierarchy. The similarities are converted to distances, aggregated to entity distances, and embedded with multidimensional scaling (MDS) into the configured number of feature-vector dimensions.

Recommended if the taxonomy features a deep, multi-level hierarchy.

Mapping

Calculates distances between the mapped taxonomy values using the configured distance metric. The distances are aggregated to entity distances and embedded with MDS into the configured number of feature-vector dimensions.

Recommended if the taxonomy contains explicit mapping values (e.g., continuous numerical scales).

One-Hot

Encodes the taxonomy values directly as binary feature-vector dimensions. No similarity or distance calculation, aggregation, or MDS is performed.

Recommended for flat categories or non-tree structures where hierarchical semantic distance is uniform and no mapping has been specified.
